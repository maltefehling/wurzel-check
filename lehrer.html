Wurzel-Check · Lehrkraft

Alle Daten bleiben in diesem Browser auf diesem Gerät. Nichts wird hochgeladen. Namen gibst du hier nirgends ein – die Zuordnung Nummer → Name steht nur auf deiner ausgedruckten Liste.

1 · Test starten

2 · Ergebnisse einsammeln

Schüler zeigen nach dem Abgeben einen QR-Code (enthält auch ihre Übungsstatistik). Wer auf einem anderen Gerät geübt hat, zeigt zusätzlich den „Übungsnachweis“ von der Startseite. Beides kannst du jederzeit scannen, auch schon vor dem Test.

3 · Ergebnisse

Klick auf eine Zeile zeigt die Aufgaben und Antworten. ½ = Wert richtig, Form nicht (z. B. nicht ganz vereinfacht). „Hand“ = per Code eingetragen, dann ohne Einzelantworten. Übung: Runden = komplette Probetests, Themen = Fünfer-Übungen, % = beim 1. Versuch richtig. Die Übungszahlen stammen vom Schülergerät; wer auf mehreren Geräten übt, wird zusammengezählt, sobald alle Geräte gescannt sind.
